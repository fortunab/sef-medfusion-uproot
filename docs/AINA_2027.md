# AINA 2027 preparation notes

The official AINA 2027 main conference is scheduled for 24–26 March 2027 at the Polytechnic University of Tirana, Albania. Its author page specifies Springer Lecture Notes style and a maximum of 12 pages including figures, tables, and references. The proceedings series is LNDECT. The archive linked by that author page actually supplies `svproc.cls`, so `main_aina.tex` uses that official template. The separately requested LLNCS variant is `main.tex`. They share the same scientific text, tables, and figures; bibliography and author-metadata rendering follow the respective classes.

Sources checked on 25 November 2026:

- [AINA 2027 conference](https://voyager.ce.fit.ac.jp/conf/aina/2027/)
- [Author and submission instructions](https://voyager.ce.fit.ac.jp/conf/aina/2027/Papersummit)
- [Official template archive](https://voyager.ce.fit.ac.jp/conf/aina/2027/public/For-the-authors-LECTURE-NOTES-TEMPLATES.zip)

The current conference homepage lists the submission deadline as 25 November 2026. Some older downloadable calls list 10 November; the current homepage is the more recent source. No EDAS upload, registration, copyright signature, or submission status has been performed or verified by this artifact.

## Overleaf

Upload the separate Overleaf ZIP as a new project. The ZIP root contains both entry points, the unmodified Springer class and bibliography-style files, references, generated numerical tables, and vector figures. Choose `main_aina.tex` as the main document for AINA, or `main.tex` for LLNCS. Use pdfLaTeX. No shell escape or Python execution is required. Recompile until references settle; Overleaf normally handles BibTeX automatically. The older official `svproc` class does not render the LLNCS ORCID macro; the ORCID values remain in the shared source and software citation metadata.

Run `python scripts/check_paper.py paper/main.pdf` after local edits to enforce the inclusive page limit. Avoid changing class margins, base font size, or global spacing to fit more content. The delivered page count is recorded in `paper/page_check.json` and the delivery report.

Before submission, the authors need to review the scientific conclusions, authorship and funding details, venue-specific declarations, and the current EDAS deadline and track. The artifact is a locally prepared manuscript and implementation; conference acceptance and portal eligibility are outside its validation.
