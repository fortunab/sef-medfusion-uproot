OVERLEAF ENTRY POINTS

main_aina.tex  Official AINA 2027 svproc template (recommended for AINA).
main.tex       Requested LLNCS variant.

The scientific content and measured tables are shared. Select the appropriate
main document in Overleaf settings and use pdfLaTeX. No shell escape or Python
execution is needed. Template files are supplied unchanged. Bibliography styles
are splncs03 for the official AINA variant and splncs04 for LLNCS.

The official template was obtained from the archive linked by:
https://voyager.ce.fit.ac.jp/conf/aina/2027/Papersummit

The inclusive 12-page limit applies to title, abstract, text, figures, tables,
acknowledgments, and references. Recheck both PDFs after editing.
